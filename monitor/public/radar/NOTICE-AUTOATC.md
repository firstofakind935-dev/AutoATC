# About this radar

This is a **modified fork of 24SPY** (https://github.com/tiaguinho2009/24SPY)
by **Tiago Murteira (nickname: tiaguinho_2009)**, used with his permission and
under the 24SPY licence in `LICENSE.md`: attribution required, **non-commercial
use only**. Original work: the map, tiles, airspace/waypoint data, ATC list and
flight-plan tools in `index.html`, `assets/main.js`, `assets/areas.js`,
`assets/styles.css` and `tiles/`.

## Changes made (AutoATC)

- `assets/main.js`: ATC data comes only from the public ATC24 API (the
  original also tried its author's private backend); the update check against
  the original repo and the Discord pop-up were removed; a hook draws AutoATC
  aircraft on the map.
- `index.html`: title, footer credit, loads `assets/autoatc.js` and `assets/radar-theme.css`.
- `assets/styles.css`: colours and font changed to the radar-scope palette (dark glass, phosphor green, monospace); layout untouched.
- `assets/radar-theme.css` (new): theme variables and styling for the added panels.
- `assets/autoatc.js` (new): live AutoATC aircraft layer, Ground view and
  Charts view, and the radar controller tools (data blocks, trails, speed
  leaders, ATC vectors, conflict alerts, range rings, measuring, direct-to,
  scratchpad and handoff tags), plus the scope look: range rings and a compass scale around the selected airport, a rotating sweep, a cursor range/bearing readout and Zulu clock. Written for this fork; no 24Radar code was
  copied into it.
- `islands/` (generated by `scripts/align-islands.py`): the Grindavik island
  art, toned to 24SPY's dark theme, for the part the tiles lack.
- `charts/*.json` (new): airport reference data generated by AutoATC.

## Separate third-party data

`ground/maps/` holds airport ground diagrams taken from 365Radar, which is
adapted from 24Radar by Tristan3D3 and licensed **GPLv3** (`ground/LICENSE-GPLv3`).
They are loaded as separate data files at runtime and keep that licence.
