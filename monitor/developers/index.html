Quick start

Every aircraft and airport has an xNm/yNm position on one flat world grid, in nautical miles. Multiply by a zoom factor, put a dot there, and you have a radar of the whole world. There's no map image; draw your own coastlines if you want them.

const BASE = '';

async function poll() {
  const { aircraft } = await fetch(`${BASE}/api/public/v1/traffic`).then(r => r.json());
  for (const a of aircraft) {
    if (a.xNm === null) continue;    // position couldn't be placed
    console.log(a.callsign, a.xNm, a.yNm, a.altitudeFt, a.headingDeg);
  }
}
setInterval(poll, 3000);

Endpoints

Both are GET, return JSON, need no key, and send Access-Control-Allow-Origin: *, so you can call them from any website.

The world grid

The origin is the north-west corner of the world. xNm grows east and yNm grows south, the same way screen pixels do, so screenX = xNm × zoom and screenY = yNm × zoom. world.widthNm/heightNm give the size of the whole area, for fitting it on screen.

To draw a heading or vector line, step nm × sin(heading) in x and −nm × cos(heading) in y from the aircraft.

Aircraft fields

Each item in traffic.aircraft. A field is null when it isn't known.

FieldTypeMeaning
callsignstringAs the pilot entered it, e.g. N42Y.
aircraftTypestringe.g. A220.
altitudeFtnumberAltitude in feet.
speedKtnumberSpeed in knots.
headingDegnumberHeading, 0–359.
squawkstringTransponder code, e.g. "2000".
identingbooleanPilot pressed IDENT recently. Highlight them.
xNm, yNmnumberPosition on the world grid. null if it couldn't be placed.
referenceAirportstringICAO code of the airport the raw position is measured from.
distanceNmnumberDistance from referenceAirport in nautical miles.
bearingDegnumberBearing from referenceAirport, degrees clockwise from north.
fixAgeSecnumberSeconds since the pilot's last manual position correction. Above ~60 the estimate is drifting; consider fading the target.
reportAgeMsnumberHow old this report is. Aircraft drop off after 30 s without a report.
assignedHeadingDegnumberHeading ATC has vectored this aircraft onto, if any.
vectorReasonstringWhy, e.g. "vectors ILS 25C".

Starter radar

A complete radar in one HTML file, with no libraries and no build step. It shows the whole world with airports, data blocks, heading leader lines, ATC vectors, history trails, a grid, and pan and zoom. Download it, open it in a browser, and start changing it.

Open full screen

Drag to pan, scroll to zoom, double-click to reset. The download is already pointed at this server. To aim a copy somewhere else, add ?api=https://other-server to its URL.

Usage notes

  • Poll every 2 seconds or slower. Positions only update every few seconds, so faster polling just costs everyone bandwidth.
  • Positions are estimates. They come from each pilot's companion app reading their own game screen, so they can drift. Don't present them as exact.
  • Only pilots running the companion app appear. Everyone else is invisible to this API.
  • Airport positions vary in accuracy. Each airport's placement is measured, derived (offset from a measured one) or estimated (rough).
  • v1 won't break. Fields may be added, but existing ones won't be renamed or removed. A breaking change would ship as /v2 alongside it.
