Quick start

Each aircraft's position is a distance and bearing from a reference airport. Pick an airport, plot every aircraft around it, and you have a radar. Bring your own map if you want one.

const BASE = '';

async function poll() {
  const { aircraft } = await fetch(`${BASE}/api/public/v1/traffic`).then(r => r.json());
  for (const a of aircraft) {
    console.log(a.callsign, a.referenceAirport, a.distanceNm, a.bearingDeg, a.altitudeFt);
  }
}
setInterval(poll, 3000);
import time, requests

BASE = ""

while True:
    data = requests.get(f"{BASE}/api/public/v1/traffic", timeout=5).json()
    for a in data["aircraft"]:
        print(a["callsign"], a["referenceAirport"], a["distanceNm"], a["bearingDeg"])
    time.sleep(3)

Endpoint

GET /api/public/v1/traffic returns every aircraft with a fresh position report. It's JSON, needs no key, and sends Access-Control-Allow-Origin: *, so you can call it from any website. Poll it every 2–5 seconds.

{
  "generatedAt": "2026-10-08T11:24:22.364Z",
  "aircraft": [
    { "callsign": "N42Y", "aircraftType": "A220",
      "referenceAirport": "IRFD", "distanceNm": 12, "bearingDeg": 230,
      "altitudeFt": 4400, "speedKt": 240, "headingDeg": 270, ... }
  ]
}

Plotting a position

bearingDeg is degrees clockwise from north, measured from referenceAirport. To turn it into x/y in nautical miles from that airport (east and north positive):

x = distanceNm * sin(bearingDeg)
y = distanceNm * cos(bearingDeg)

Then scale nautical miles to pixels however your radar likes. Heading and vector lines work the same way: step along sin(heading), cos(heading) from the aircraft. Aircraft near different airports use different reference airports, so either show one airport at a time (like the starter radar) or place the airports yourself.

Aircraft fields

Each item in traffic.aircraft. A field is null when it isn't known.

FieldTypeMeaning
callsignstringAs the pilot entered it, e.g. N42Y.
aircraftTypestringe.g. A220.
altitudeFtnumberAltitude in feet.
speedKtnumberSpeed in knots.
headingDegnumberHeading, 0–359.
squawkstringTransponder code, e.g. "2000".
identingbooleanPilot pressed IDENT recently. Highlight them.
referenceAirportstringICAO code of the airport the position is measured from.
distanceNmnumberDistance from referenceAirport in nautical miles.
bearingDegnumberBearing from referenceAirport, degrees clockwise from north.
fixAgeSecnumberSeconds since the pilot's last manual position correction. Above ~60 the estimate is drifting; consider fading the target.
reportAgeMsnumberHow old this report is. Aircraft drop off after 30 s without a report.
assignedHeadingDegnumberHeading ATC has vectored this aircraft onto, if any.
vectorReasonstringWhy, e.g. "vectors ILS 25C".

Starter radar

A complete radar in one HTML file, with no libraries and no build step. It's a radar scope centred on an airport you pick, with range rings, data blocks, heading leader lines, ATC vectors and history trails. Download it, open it in a browser, and start changing it.

Open full screen

Pick the airport at the top left, and scroll to change range. The download is already pointed at this server. To aim a copy somewhere else, add ?api=https://other-server to its URL.

Usage notes

  • Poll every 2 seconds or slower. Positions only update every few seconds, so faster polling just costs everyone bandwidth.
  • Positions are estimates. They come from each pilot's companion app reading their own game screen, so they can drift. Don't present them as exact.
  • Only pilots running the companion app appear. Everyone else is invisible to this API.
  • v1 won't break. Fields may be added, but existing ones won't be renamed or removed. A breaking change would ship as /v2 alongside it.
