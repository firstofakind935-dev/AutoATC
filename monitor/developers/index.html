Quick start

Every aircraft already comes with map.x/map.y, pixel coordinates on the shared world map image. Draw the image, put a dot at those coordinates, and you have a radar.

const BASE = '';

async function poll() {
  const { aircraft } = await fetch(`${BASE}/api/public/v1/traffic`).then(r => r.json());
  for (const a of aircraft) {
    if (!a.map) continue;            // position couldn't be placed on the map
    console.log(a.callsign, a.map.x, a.map.y, a.altitudeFt, a.headingDeg);
  }
}
setInterval(poll, 3000);

Endpoints

All endpoints are GET, return JSON (except the map image), and send Access-Control-Allow-Origin: *, so you can call them from any website.

EndpointWhat it returnsPoll
/api/public/v1/trafficEvery aircraft with a fresh position report, plus the map info.Every 2–5 s
/api/public/v1/airportsEvery airport's position on the world map, plus the map info.Once
/api/public/v1/map.pngThe world map image that map.x/map.y refer to.Once

Map info

Both JSON endpoints include a map object describing the image:

{
  "imageUrl": "/api/public/v1/map.png",
  "width": 937, "height": 706,   // image size in pixels
  "pxPerNm": 24,                 // pixels per nautical mile
  "projection": "x = anchor.x + distanceNm * pxPerNm * sin(bearing); y = anchor.y - distanceNm * pxPerNm * cos(bearing)"
}

North is up. Pixel y grows downward. To draw a heading or vector line, step nm × pxPerNm pixels along sin(heading) for x and −cos(heading) for y.

Aircraft fields

Each item in traffic.aircraft. A field is null when it isn't known.

FieldTypeMeaning
callsignstringAs the pilot entered it, e.g. N42Y.
aircraftTypestringe.g. A220.
altitudeFtnumberAltitude in feet.
speedKtnumberSpeed in knots.
headingDegnumberHeading, 0–359.
squawkstringTransponder code, e.g. "2000".
identingbooleanPilot pressed IDENT recently. Highlight them.
map{x, y}Pixel position on map.png. null if it couldn't be placed.
referenceAirportstringICAO the raw position is measured from.
distanceNm, bearingDegnumberRaw position: distance and bearing from referenceAirport. Use these if you bring your own map.
fixAgeSecnumberSeconds since the pilot's last manual position correction. Above ~60 the estimate is drifting; consider fading the target.
reportAgeMsnumberHow old this report is. Aircraft drop off after 30 s without a report.
assignedHeadingDegnumberHeading ATC has vectored this aircraft onto, if any.
vectorReasonstringWhy, e.g. "vectors ILS 25C".

Starter radar

A complete radar in one HTML file, with no libraries and no build step. It has the map, airports, data blocks, heading leader lines, ATC vectors, history trails, pan and zoom. Download it, open it in a browser, and start changing it.

Open full screen

Drag to pan, scroll to zoom, double-click to reset. The download is already pointed at this server. To aim a copy somewhere else, add ?api=https://other-server to its URL.

Usage notes

  • Poll every 2 seconds or slower. Positions only update every few seconds, so faster polling just costs everyone bandwidth.
  • Positions are estimates. They come from each pilot's companion app reading their own game screen, so they can drift. Don't present them as exact.
  • Only pilots running the companion app appear. Everyone else is invisible to this API.
  • v1 won't break. Fields may be added, but existing ones won't be renamed or removed. A breaking change would ship as /v2 alongside it.
  • Airport placement varies in accuracy. Each airport in /airports has a confidence note. direct means it was measured on the image; fitted-only is a rough estimate.
