Quick start

Every aircraft and airport has an xNm/yNm position on one flat world grid, in nautical miles. Multiply by a zoom factor, put a dot there, and you have a radar of the whole world. There's no map image, but real maps line up exactly if you want coastlines and airport diagrams.

const BASE = '';

async function poll() {
  const { aircraft } = await fetch(`${BASE}/api/public/v1/traffic`).then(r => r.json());
  for (const a of aircraft) {
    if (a.xNm === null) continue;    // position couldn't be placed
    console.log(a.callsign, a.xNm, a.yNm, a.altitudeFt, a.headingDeg);
  }
}
setInterval(poll, 3000);

The world grid

The origin is the north-west corner of the world. xNm grows east and yNm grows south, the same way screen pixels do, so screenX = xNm × zoom and screenY = yNm × zoom. world.widthNm/heightNm give the size of the whole area, for fitting it on screen.

To draw a heading or vector line, step nm × sin(heading) in x and −nm × cos(heading) in y from the aircraft.

Drawing real maps

The world grid is tied exactly to the game's own coordinates, so any map drawn in game coordinates lines up with the traffic. /api/public/v1/frame gives the 2×3 matrices [[a, b, c], [d, e, f]]; apply one to a point (u, v) as x = a·u + b·v + c, y = d·u + e·v + f.

MatrixFrom → toUse it for
gridFromGamegame units (100 studs) → grid nmThe map SVGs of 24RC and 24Radar (coast.svg, each airport's GROUND.svg) are drawn in game units: wrap them in an SVG <g transform="matrix(a d b e c f)"> and they sit on the grid. Accurate to 3–60 m.
gameFromGridgrid nm → game unitsThe other way: put an aircraft on a ground chart you draw in its own units.
spyFromGame, gridFromSpy24SPY map units ↔ grid nm24SPY's 1200 × 1200 map tiles and its airport/waypoint coordinates. Accurate to about 0.03 nm.
 
// put 24RC's coast.svg (game units) under a radar drawn in nm

Aircraft fields

Each item in traffic.aircraft. A field is null when it isn't known.

FieldTypeMeaning
callsignstringAs the pilot entered it, e.g. N42Y.
aircraftTypestringe.g. A220.
altitudeFtnumberAltitude in feet.
speedKtnumberSpeed in knots.
headingDegnumberHeading, 0–359.
squawkstringTransponder code, e.g. "2000".
identingbooleanPilot pressed IDENT recently. Highlight them.
xNm, yNmnumberPosition on the world grid. null if it couldn't be placed.
referenceAirportstringICAO code of the airport the raw position is measured from.
distanceNmnumberDistance from referenceAirport in nautical miles.
bearingDegnumberBearing from referenceAirport, degrees clockwise from north.
fixAgeSecnumberSeconds since the last position fix (an automatic minimap match, a stand entry or an ATC clearance). Fixes normally come every couple of seconds; during a gap (open sea, short final to a small island) the position is carried along the aircraft's track for up to 30 s and then held, so above ~30 consider fading the target.
reportAgeMsnumberHow old this report is. Aircraft drop off after 30 s without a report.
assignedHeadingDegnumberHeading ATC has vectored this aircraft onto, if any.
vectorReasonstringWhy, e.g. "vectors ILS 25C".

Starter radar

A complete radar in one HTML file, with no libraries and no build step. It shows the whole world with airports, data blocks, heading leader lines, ATC vectors, history trails, a grid, and pan and zoom. Download it, open it in a browser, and start changing it.

Open full screen

Drag to pan, scroll to zoom, double-click to reset. The download is already pointed at this server. To aim a copy somewhere else, add ?api=https://other-server to its URL.

Usage notes

  • Poll every 2 seconds or slower. Positions only update every few seconds, so faster polling just costs everyone bandwidth.
  • Positions are estimates. They come from each pilot's AutoATC companion or tracker matching their own game minimap against the map (runways, taxiways, buildings, coastline) every couple of seconds - typically within a stand's width on the ground, but a gap in fixes or a look-alike match can still put one off for a while. Don't present them as exact; fixAgeSec tells you how fresh they are.
  • Only pilots running the AutoATC companion, pilot app or tracker appear. Everyone else is invisible to this API.
  • Airport positions are the airports' reference points from 24SPY, placed on the grid through the exact frame (placement: "measured"); a few without one are derived or estimated. Distances and bearings in /traffic are measured from these same points.
  • v1 won't break. Fields may be added, but existing ones won't be renamed or removed. A breaking change would ship as /v2 alongside it.
